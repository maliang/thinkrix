# 多语言

Thinkrix 多语言和 Trix 前端协议保持一致。配置入口：

```php
'locale' => env('THINKRIX_LOCALE', 'zh-CN'),
'fallback_locale' => 'en-US',
'languages' => [
    'zh-CN' => ['label' => '中文', 'file' => 'zh-cn', 'naive_locale' => 'zh-CN'],
    'en-US' => ['label' => 'English', 'file' => 'en-us', 'naive_locale' => 'en-US'],
],
```

## 语言文件加载顺序

同名 key 后加载会覆盖前加载：

1. Thinkrix 包内 `lang/{locale}.php`
2. 项目 `config/lang/{locale}.php`
3. 模块 `lang/{locale}.php`

例如新增日文：

```php
'languages' => [
    'ja-JP' => ['label' => '日本語', 'file' => 'ja-jp', 'naive_locale' => 'en-US'],
],
```

然后创建：

```text
config/lang/ja-jp.php
Modules/Demo/lang/ja-jp.php
```

## 接口

- `GET /api/admin/translations?locale=zh-CN`
- `POST /api/admin/locale`，请求体：`{ "locale": "en-US" }`

为兼容系统页内接口，也保留：

- `GET /api/admin/system/translations`
- `POST /api/admin/system/locale`

## 使用建议

菜单标题、schema 表单标签、按钮文案和消息提示都应使用语言 key，例如 `system.dashboard.total_users`。如果界面直接显示 key，说明当前语言文件缺少对应值，或后端没有把该 key 通过 `__t()` 翻译。
